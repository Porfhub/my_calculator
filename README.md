# Ясномера

Понятные расчёты для финансовых решений.

[yasnomera.ru](https://yasnomera.ru/) — независимый, прозрачный и образовательный сервис финансовых калькуляторов. Он помогает сравнивать сценарии на собственных вводных и не является банком, брокером, инвестиционной платформой или финансовым советником.

## Возможности

- ипотечный расчёт и досрочные погашения;
- сравнение покупки жилья и аренды;
- полная стоимость кредита;
- срок достижения финансовой цели и запас финансовой подушки;
- изменение покупательной способности;
- сравнение зарплаты с официальными ориентирами;
- сравнение расходов на автомобиль и такси;
- стоимость покупки в часах работы;
- оценка расходов на воспитание ребёнка.

Расчёты выполняются в браузере. Официальные финансовые данные проходят fail-closed валидацию; источник, период и ограничения показываются в интерфейсе.

## Локальный запуск

Проект является статическим приложением. Запустите HTTP-сервер из корня репозитория и откройте `index.html`, например:

```powershell
python -m http.server 8000
```

## Production deployment

Публикуется содержимое корня репозитория без шага сборки. Канонический production-домен — `yasnomera.ru`; существующий проект и внутренние идентификаторы провайдера развёртывания следует сохранять, пока их изменение не будет выполнено отдельной инфраструктурной миграцией.

Перед выпуском проверьте HTTPS, привязку домена, `robots.txt`, `sitemap.xml`, PWA manifest и отсутствие ошибок service worker. Архитектура и эксплуатационные детали описаны в [TECH_PASSPORT.md](TECH_PASSPORT.md), состояние релиза — в [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md).
