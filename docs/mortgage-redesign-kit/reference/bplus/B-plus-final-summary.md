# B+ Final — финальный summary

Принятый вектор B+ сохранён. Production и GitHub не изменялись. Обновлён основной самостоятельный HTML-прототип; предыдущие локальные B и B+ сохранены для сравнения.

## Founder comments учтены

**A — разделение досрочных:** регулярная доплата — основная карточка; разовые — самостоятельная секция на другой поверхности с собственным заголовком, объяснением, переходом к графику, формой и списком. Можно использовать один тип доплат или оба. Результаты подписаны по области расчёта, две экономии нельзя складывать.

**B — срок:** hero сохраняет срок условий. Закрытие раньше и сокращение срока показаны в досрочных сценариях. Для комфортного/известного платежа корректная подпись «Срок без досрочных». PNG также различает оба срока.

**C — mobile CTA:** «Показать результат» удалено. Остаётся навигационный sticky «К результату», расчёт автоматический.

**D — ЦБ:** две короткие строки рядом с ипотечной ставкой. В прототипе «нет данных», без выдуманного актуального числа. Действующие значение/дата/источник подключаются при production integration.

**E — график:** служебная фраза «Первый год уже раскрыт» удалена; первый год открыт самим интерфейсом. Редактирование разовых платежей по месяцам сохранено.

## Проверено

Desktop 1440×900 и mobile 390×844; light/dark, включая mobile dark; initial и scrolled states; ползунки и месяцы; регулярные, разовые отдельно и вместе; обе стратегии; hero term semantics; график, месяц-specific editing, sticky; комфортный/известный платёж и страховка; PNG и share.

PNG preview проверен на обоих layouts; файл 1200×760 реально скачан из standalone document. Share-ссылка открыта, условия и доплаты восстановлены. В mobile QA-iframe tool не перехватывает download event; мобильный preview проверен отдельно. Сохранены 18 captures и скачанный PNG.
