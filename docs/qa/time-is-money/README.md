Целые офисные дни выбираются кнопками. Дробное или выходящее за пределы быстрых кнопок значение, а также локальная ошибка автоматически показывают точное поле. Выбор кнопки закрывает поле и сохраняет фокус. Проверены Enter, Space и восстановление дробных дней из ссылки.

Графитовая тема по фактическим цветам браузера даёт около 11,03:1 для надзаголовка, 9,17:1 для валюты и 7,19:1 для выбранной кнопки. В обеих темах проверенные обычные подписи, ошибки и отключённые действия выше 4,5:1, а контур фокуса выше 3:1.

## Приватность и аналитика

Начальный inline-скрипт забирает семь полей из входящего URL и вызывает `replaceState` до ресурсов и `ym('init')`. При запрете `replaceState` эта загрузка восстанавливает расчёт из захваченных значений и пропускает инициализацию Метрики. Для подресурсов действует `strict-origin`, у CDN экспортера и резервного пикселя указан `no-referrer`. Stub проверяет URL и явный referrer в `init`, исходящие Referer, сохранение UTM/yclid, число записей истории и единственный `calculate_success` без параметров после первого валидного изменения. Ссылки, создаваемые вручную, содержат только параметры расчёта.

Первый HTTP-запрос по старой ссылке уже содержит query. Эти значения могут оказаться в журналах сервера или CDN до выполнения JavaScript. Проверка аналитики использует stub и заголовки запросов к ресурсам, а клиентские данные калькулятора помечены для исключения из записи Вебвизора. [Документация Вебвизора](https://yandex.ru/support/metrica/ru/webvisor/settings)

## Воспроизведение

- `npm test` — 178 из 178.
- `npm run validate:data` — schema, semantics и freshness для ставок, инфляции и регионов.
- `node dev_tools/time-is-money-browser-qa.cjs` — Playwright с установленным Chrome. Установленный вне репозитория Playwright можно указать через `PLAYWRIGHT_MODULE`, для Edge задать `QA_BROWSER=msedge`. По умолчанию снимки «до» берутся из подтверждённого Git blob. `TIME_PRODUCTION_HTML` позволяет передать загруженный HTML, а `TIME_QA_OUT` задаёт каталог вывода.
- [Прогон Chrome](browser-results.json) · [Прогон Edge](browser-results-edge.json).

Мобильные проверки выполнены в эмуляции Chromium с тач-вводом и уменьшенной высотой окна для проверки видимости поля при фокусе. Клавиатуру физического Android/iOS, Safari и экранные дикторы этот прогон не покрывает.
