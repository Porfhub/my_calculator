| Такси дешевле на | 19 896 ₽ | 238 748 ₽ |

- Пустые и нулевые прочие расходы дают 418 748 ₽ за машину в год. При 12 000 ₽/год денежных расходов становится 144 748 ₽, стоимость машины — 430 748 ₽.
- При такси 1 163,19 ₽ за поездку итог «Расходы близки». Такси дороже на 0,40 ₽/год и примерно на 0,03 ₽/мес. Порог близости — 1% большей годовой суммы.
- При нуле поездок такси стоит 0 ₽, машина со стартовыми постоянными расходами и потерей стоимости — 401 000 ₽/год. Цена километра — «Нет пробега». Если обнулить страховку, обслуживание и потерю стоимости, обе суммы равны нулю и вердикт «Расходы равны».
- Ручная ставка 12% даёт возможный доход 312 000 ₽/год, стоимость машины в сценарии 730 748 ₽/год и разницу с такси 550 748 ₽/год. Основной вердикт, сводка и полосы используют базовый расчёт.

## Проверки

- `npm test` — 235 тестов. `npm run validate:data` — схемы, семантика и свежесть трёх наборов данных.
- 722 браузерных проверки в [протоколе](browser-results.json). Периоды, две суммы и пропорции полос, разбивка, ошибки, пустой и нулевой ввод, близкие и равные итоги, сценарий, пресеты, клавиши Enter и Space, фокус, переход из сводки и реакция на уменьшение Visual Viewport.
- Контраст измерен по вычисленным цветам Chrome. Светлая / графитовая: заголовок результата 8,88 / 9,51, вторичный текст 6,10 / 8,06, граница поля 3,30 / 4,23, фокус 5,84 / 9,51, заполнение полосы относительно дорожки 6,67 / 5,55.
- Реальный html2canvas скачал четыре PNG. Проверены имя, читаемость, контекст первого года, суммы и отдельные строки расходов. Временный DOM клона и обёртки покрыт маской. Клон очищается после скачивания. При ошибке в основном вводе PNG и share результата недоступны.
- Clipboard API Chrome копировал только origin и путь при наличии тестовых query и fragment. Web Share проверен на границе API с выбранным периодом, базовым вердиктом и чистой ссылкой. Ошибка API проверена с переходом в clipboard.
- Ипотека сравнивалась при одинаковом URL, данных и темах после завершения отрисовки графика. На 1366 и 320 px в обеих темах совпали пиксели видимой области.
- Локальная проверка статического архива воспроизводит список 36 файлов, контроль их хешей, запрет симлинков и точки входа PNG у десяти калькуляторов.

## Вебвизор и события

Перехваченный вызов `init` подтверждает `webvisor:true` для счётчика `110360838`. Маски проверены на финансовых полях, на пробеге, ползунке, результате, полосах, сводке, сценарии, уведомлении и временном дереве PNG. Ползунок также исключён из карты кликов. Тесты проверили цели с единственным идентификатором в аргументах. Невалидное, эквивалентное и программное изменение, смоделированное автозаполнение, сценарий, анкета и период не создают конверсии. Реально меняющий модель пресет создаёт одну конверсию.
