Базовые 418 748 ₽ состоят из 132 748 ₽ денежных расходов и 286 000 ₽ потери стоимости. Потенциальный упущенный доход при 14% от 2 600 000 ₽ составляет 364 000 ₽. «Расходы + упущенный доход» даёт 782 748 ₽ условных затрат, разница с такси — 602 748 ₽ за первый год при таком предположении. В карточке отдельно поясняется смысл итога, рядом со ставкой указаны негарантированный доход и сохранение базового сравнения.

Прошли [228 проверок Chrome](browser-results.json) на 1366, 390, 375 и 320 CSS px в обеих темах. Проверены обе стороны сравнения, равенство при 0% и положительной ставке, нулевой упущенный доход, неверная ставка, смена периода, отсутствие горизонтального скролла и маскирование новых сумм. Реально скачаны четыре PNG с открытым сценарием. PNG и Web Share передают базовый результат, цели аналитики сохранили прежние идентификаторы. Отправка Метрики была заблокирована, Web Share проверялся на границе API.
