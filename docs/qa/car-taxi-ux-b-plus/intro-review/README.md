Вступление состоит из H1 и подзаголовка. На 1366 px начало калькулятора поднялось на 29 CSS px. На мобильных подзаголовок занимает две строки, вердикт и сумма целиком видны на первом экране. Общая шапка и её фирменный знак совпали с базой.

[154 проверки Chrome](browser-results.json) подтвердили геометрию, отсутствие горизонтального переполнения, стартовый и годовой итоги, сценарий при 10%, переход из мобильной сводки и реальное скачивание PNG. При открытии страницы, смене периода и вводе ставки цель расчёта не отправляется. Запросы Метрики блокировались. `npm test` — 241 тест, `npm run validate:data` — три набора.
