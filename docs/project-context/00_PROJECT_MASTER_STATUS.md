## Продукт и границы

**Ясномера — «Понятные расчёты для финансовых решений».** Независимые образовательные расчёты в браузере. Не банк, брокер, советник, витрина предложений или сбор заявок. Официальные данные, пользовательские условия и допущения модели различаются.

Статический сайт: 11 HTML, общие JS/CSS, JSON и PWA; без frontend-сборки/backend. Бренд, домен yasnomera.ru, репозиторий Porfhub/my_calculator и GitHub → Yandex инфраструктура сохраняются.

При уменьшении платежа указано, что hero содержит первый обязательный платёж, последующие меняются по графику. Новая ипотека теперь уточняется до месяцев; для нулевых дополнительных месяцев старые результаты сохранены.

Сохранены новая/действующая ипотека, история, комфортный/известный платёж, страховка, обе стратегии и сочетания доплат, авторасчёт, графики, помесячное редактирование, состояния и восстановление. Полный PNG использует прежний clone/canvas/Blob exporter. При ошибке primary render старый результат теперь очищается и экспорт закрывается.

Проверка обнаружила, что прежняя production share-кнопка копировала только текущий URL: сериализации state не было. Добавлены воспроизводимые ипотечные URL и fallback при недоступном clipboard. Обычные прежние URL продолжают открывать исходный пример.
