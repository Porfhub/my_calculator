## Ипотечный редизайн: реализация в PR, ещё не main/production

Основание — поручение владельца от 31.10, hybrid-desktop-approved.png / hybrid-mobile-approved.png и B+ Final из приложенного архива. Изображения — визуальный ориентир; демонстрационные формулы прототипа не используются.

Реализованы payment-first hero, компактная зелёно-графитовая шапка, mobile hero перед формой, нейтральная графитовая тема, спокойный состав выплат с диаграммой, заметные PNG/share и график по месяцам. Регулярные и разовые доплаты — отдельные поверхности; стратегия общая. Regular-only и combined/one-time-only сравниваются с теми же условиями без любых досрочных. Экономии не складываются.

Hero показывает срок базовых условий либо «Срок без досрочных» для выведенного из платежа срока. Фактическое закрытие — в эффекте доплат. При уменьшении платежа указано, что hero содержит первый обязательный платёж, последующие меняются по графику. Новая ипотека теперь уточняется до месяцев; для нулевых дополнительных месяцев старые результаты сохранены.

Сохранены новая/действующая ипотека, история, комфортный/известный платёж, страховка, обе стратегии и сочетания доплат, авторасчёт, графики, помесячное редактирование, состояния и восстановление. Полный PNG использует прежний clone/canvas/Blob exporter. При ошибке primary render старый результат теперь очищается и экспорт закрывается.

Проверка обнаружила, что прежняя production share-кнопка копировала только текущий URL: сериализации state не было. Добавлены воспроизводимые ипотечные URL и fallback при недоступном clipboard. Обычные прежние URL продолжают открывать исходный пример.

Мобильные ползунки остаются скрыты по контракту PR #90; точный числовой ввод основной. Desktop ползунки непосредственно под ценой и взносом. Sticky один: обязательный платёж и «К результату»; скрыт при видимом hero/редактировании/сжатом viewport клавиатуры.
