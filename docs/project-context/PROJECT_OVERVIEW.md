# Ясномера · карта проекта

[Ясномера](https://yasnomera.ru/) — русскоязычный образовательный сервис для людей, сравнивающих варианты расходов, накоплений и доходов. «Понятные расчёты для финансовых решений» означает видимые допущения, объяснимые цифры и возможность изменить свой сценарий. Проект не принимает заявки, не генерирует лиды и не продаёт банковские или брокерские продукты.

## Сайт и инструменты

[Главная](../../index.html) ведёт в каталог 3 + 3 + 4. Состав, реализация и QA каждой страницы описаны в паспорте.

| Направление | Калькуляторы |

| Накопления и деньги | [Финансовая цель](../pages/millionaire.md), [Финансовая свобода](../pages/financial-freedom.md), [Инфляционный шредер](../pages/inflation-shredder.md) |
| На каждый день | [Цена времени](../pages/time-is-money.md), [Машина или такси](../pages/car-vs-taxi.md), [Стоимость воспитания ребёнка](../pages/genetic-wealth.md), [Сравнение зарплаты](../pages/wealth.md) |

Общий интерфейс использует светлую и графитовую темы, навигацию к каталогу и блоки с методологией. Обновлённые страницы ставят главный ответ и необходимые поля выше дополнительных настроек. PNG и ссылки имеют разные контракты на разных страницах. [Индекс паспортов](../pages/README.md)

[Дизайн-система](../design-system/README.md) описывает явное подключение общих компонентов и правила сохранения индивидуальности страниц.

## Технологии, данные и публикация

HTML, CSS и JavaScript обслуживаются как статический сайт, основная математика выполняется в браузере. Общие модули отвечают за тему, форматирование, получение данных, состояния калькуляторов и экспорт. Веб-приложение использует service worker и manifest. Ставка Банка России, историческая инфляция Росстата / ЕМИСС и региональные ориентиры поступают через проверяемые JSON. Применимость, свежесть и поведение при отказе зависят от страницы. [Техническая передача](02_TECHNICAL_HANDOFF.md)

GitHub Actions собирает и проверяет точный статический пакет из [репозитория](https://github.com/Porfhub/my_calculator), публикует его в Yandex Cloud Object Storage и выполняет HTTP-проверки. Метрика используется для аналитики, Директ — для отдельных рекламных тестов. Статусы выпусков и подтверждения по рекламе находятся в [master status](00_PROJECT_MASTER_STATUS.md).

## Как работать с контекстом

1. Начни новый чат внутри ChatGPT Project и назови страницу, цель задачи и нужный паспорт. Используй [инструкцию по источникам и короткие задания](04_CHATGPT_PROJECT_SOURCES.md).
2. В режиме «Работа» исследуй актуальный сайт, финансовую модель и мобильный/настольный интерфейс. Обсуди и согласуй бриф с владельцем.
3. В Codex используй [AGENTS.md](../../AGENTS.md), паспорт, актуальный код и тесты. Реализация, проверка и обновление паспорта входят в один PR. Владелец принимает решение о merge. Статус выпуска подтверждается workflow и production.
4. За состоянием релизов обращайся к [master status](00_PROJECT_MASTER_STATUS.md), за историей выбора к [журналу решений](01_DECISION_LOG.md). [Зеркало Drive](03_CONTEXT_MIRROR_RUNBOOK.md) доставляет копии из GitHub main.

[Foundation](../PROJECT_FOUNDATION.md), [старый статус](../PROJECT_STATUS.md), [release notes](../RELEASE_NOTES.md), [технический паспорт ранних выпусков](../../TECH_PASSPORT.md), [комплект ипотечных прототипов](../mortgage-redesign-kit/ROADMAP.md) и [материалы главной](../homepage-redesign/README.md) сохраняют исторический контекст. Для поведения страницы используй соответствующий паспорт и код, для визуальных доказательств — датированные QA-материалы.
