## Runtime и расчёты

Статический сайт без приложения на сервере и без runtime-сборки. Большинство моделей и UI-адаптеров находятся в HTML. Исключения включают [модель покупки и аренды](../../js/rent-vs-mortgage-model.js), [сравнение доходов](../../js/income-comparison.js) и [НДФЛ](../../js/ndfl.js). [calculator-state](../../js/calculator-state.js) разделяет загрузку, результат, невалидный ввод, невозможность расчёта, отсутствие данных и ошибку. Точный набор состояний зависит от страницы. На ипотеке ошибка основного рендера очищает старый итог, а отказ графика диагностируется отдельно. Экспорт требует актуального результата.

[theme.js](../../js/theme.js) и [product-polish.css](../../css/product-polish.css) содержат общие компоненты. Часть страниц использует CDN Tailwind, Chart.js или html2canvas. Главная использует собственный CSS и статический каталог, а новые страницы могут иметь локальные компоненты. [manifest](../../manifest.webmanifest) и [service worker](../../sw.js) определяют PWA. Для HTML применяется network-first, политика данных и список precache находятся в самом SW. Browser QA с отключённым SW и локальными CDN-ресурсами не заменяет production smoke и отдельную проверку офлайн.

[Дизайн-система](../design-system/README.md) поставляется отдельным [CSS](../../css/design-system.css). Токены наследуются внутри `.yn-scope`, компоненты требуют явных классов `yn-*`. Графитовые токены используют существующий `html.dark`. В main CSS подключён после `product-polish.css` в трёх HTML пилота. [Ветка расширения](../qa/calculator-headers/README.md) подключает его ещё в шести шапках и сохраняет один обработчик темы на страницу. В SW v18 `addAll` обязателен для собственных URL. Перед активацией переносятся сохранённые CDN-ответы v17, а недостающие библиотеки загружаются независимо. При чистой установке Tailwind CDN не проходит CORS, поэтому доступность собственных файлов офлайн подтверждена, а полное оформление зависит от ранее сохранённого Tailwind. [QA чистой установки и обновления кеша](../qa/calculator-header-pilot/README.md)

## Финансовые данные

| Пакет | Назначение и жизненный цикл |
| --- | --- |
| [rates.json](../../rates.json) | Ключевая ставка Банка России с происхождением, датой действия и отметкой получения. Мягкий TTL 72 ч, жёсткий 7 дней. Ставка ЦБ справочна для ипотечной ставки пользователя. |
| [inflation.json](../../inflation.json) | Годовой ряд Росстата / ЕМИСС. Политика ожидаемого года использует границу 31 января UTC и окно stale до 90 дней. Исторический средний темп служит модельным допущением там, где его используют страницы. |
| [regions.json](../../regions.json) | Официальные региональные ориентиры с частичным охватом и provenance по метрике. Несовместимые или отсутствующие значения скрываются. |

[api.js](../../js/api.js) читает JSON и проверяет применимость данных для клиентов. [Схемы](../../schemas) и [validators](../../data_validation) проверяют форму, семантику, свежесть и происхождение. Updater публикует проверенный результат атомарно. При отказе сохраняется последний допустимый пакет, а после жёсткого ограничения применяется политика unavailable. Данные нельзя заменять предположением под видом факта. UI имеет локальные проверки и ограничения, которые нужно сверять с паспортами. Известный пример отдельного сценарного fallback описан в [паспорте авто/такси](../pages/car-vs-taxi.md).

## Экспорт, аналитика и приватность

[ui-utils.js](../../js/ui-utils.js) содержит общие действия и рендер PNG. Часть страниц экспортирует из изолированного DOM, ипотека строит отдельный компактный отчёт из актуального снимка расчёта. Результат и серия графика должны относиться к тому же вводу. Share может быть канонической ссылкой, сообщением с итогом или ссылкой со сценарием. Перед изменением проверь конкретную реализацию, ручной clipboard fallback и доступность после ошибки.

События Метрики имеют постраничный контракт. В обновлённых сценариях запуск из примера, открытие ссылки, смена темы и невалидный ввод не должны подменять пользовательский валидный расчёт. У ипотечной диагностики категориальные stage/kind без сумм. Проверяй URL и referrer, поля и результаты в Вебвизоре, клонированный DOM экспорта, смысл goals и фактический приём событий. Локальный перехват Метрики не подтверждает запись в кабинете. Некоторые старые страницы используют иные триггеры и маскирование.

## CI и выпуск

- Установи зависимости через npm в рабочей среде. `npm test` запускает Node-тесты UI-state, математических контрактов и изоляции updater. `npm run validate:data` проверяет реальные snapshots по текущим часам. Тестовые fixture из PR #91 должны быть независимы от возраста production JSON.
- [Validate Financial Data](../../.github/workflows/data-validation.yml) запускает гейты по своему набору путей. [Update Mortgage Rates](../../.github/workflows/rates.yml) обслуживает данные по расписанию. Health advisory и блокирующий publish gate различаются.
- [Deploy Yandex Object Storage Mirror](../../.github/workflows/deploy-yandex-object-storage.yml) архивирует main, исключает служебные файлы, сверяет 36 путей, Git-хеши, отсутствие симлинков и PNG-маркеры, синхронизирует Object Storage, затем проверяет URL, включая CSS дизайн-системы. Успешный updater на main может запустить deploy через workflow_run. PR #99 исключил корневой AGENTS.md и добавил поддержку PNG-маркера «Финансовой цели». Docs и dev_tools исключены из runtime-пакета.
- При пользовательских изменениях запускай профильные числовые и browser QA, обе темы и mobile/desktop. Подтверждай merge, deploy и фактическое поведение раздельно. Настройку обязательных веточных checks сверяй в GitHub.

Технический долг включает крупные inline-страницы, неодинаковую строгость legacy-аналитики и частичное покрытие региональных данных. Механизм доставки знаний описан в [runbook](03_CONTEXT_MIRROR_RUNBOOK.md). Изменения финансовых контрактов сопровождаются паспортами в том же PR. [Правила](../../AGENTS.md)
