# Главная Ясномеры — утверждённый вариант A

02.11.2026 основатель выбрал A «Спокойный навигатор» и поручил реализацию. B и первая версия с иллюстрацией остаются концептами, не roadmap и не production. База — main 48c3579; статус этой реализации — отдельная PR-ветка codex/homepage-navigator.

## Принято

- Главная помогает быстро выбрать расчёт. Позиционирование и бренд сохраняются.
- Статические прямые ссылки на 10 действующих калькуляторов: жильё/кредиты, накопления/деньги, на каждый день. У каждого есть понятное короткое описание.
- Ставка Банка России — вторичный официальный факт: число, дата успешной проверки, источник, предупреждение о stale/unavailable. Это не банковская ставка и не рекламное предложение.
- Light/graphite и mobile-first; на mobile компактная шапка, справка и один ряд category anchors. Общие tokens/styles пока scoped к homepage, без массового изменения калькуляторов.
- Статический каталог работает без JS/Tailwind CDN. Методология в нативном раскрытии; share остаётся с fallback при отказе clipboard/native share.
- Ипотека уже production reference. Её математика/ввод/PNG/share/цель текущим PR не меняются.

## Доставка

Реализация → целевой browser QA + 156 tests → PR → одна mobile приёмка → founder merge → штатный Yandex deploy + smoke. [Доказательства и ограничения QA](../qa/homepage-redesign/2026-11-02/README.md). Новых runtime-файлов/зависимостей/изменений deploy allowlist нет.

## Параллельный рекламный поток

Повторный ограниченный ипотечный Search-тест ведёт прямо на mortgage.html, не ожидает редизайна всего сайта. Пока рекомендация: сохранить историю существующей кампании; проверить placements/geography/strategy/счётчик и выбранную calculate_success, объявления/фразы/минус-фразы и статистику полного первого периода с разбивкой по цели/устройству/дню/поисковым запросам. Изначальный рекламный screenshot с aggregate conversions не доказывает количество calculate_success.

До проверки данных — предварительный выбор «Максимум кликов», оплата за клики, ограниченный бюджет на датированный 7-дневный тест; после проверки возможна другая настройка. Эффект оценивается по доле сопоставимых рекламных визитов с успешным расчётом и стоимости такого визита, плюс качество запросов/сессий. Это before/after с ограничениями выборки, не доказанный A/B uplift. Бюджет, даты, цена клика и запуск ещё не согласованы. Никаких расходов этим одобрением дизайна не разрешено.
