# Release notes

## Ясномера 1.0.0 — release candidate (11 сентября 2026)

### Бренд и домен

- Продукт приведён к единому имени «Ясномера» и позиционированию «понятные расчёты для финансовых решений».
- Канонические, Open Graph, Twitter/X и schema.org metadata указывают на `yasnomera.ru`.
- Название PWA, service worker cache и имена экспортируемых скриншотов синхронизированы с production-брендом.
- Добавлены production manifest, `robots.txt` и `sitemap.xml`.

### Совместимость

- Формулы, финансовые данные, пользовательские сценарии и визуальная система не изменены.
- Существующие внутренние идентификаторы инфраструктуры развёртывания можно сохранить; публичная идентичность и канонический домен от них не зависят.
